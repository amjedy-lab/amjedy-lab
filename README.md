## Привет! Я Валентин (@amjedy-lab) 🦖

Здесь я публикую свои T-REX утилиты — маленькие переносные инструменты
для Windows: один файл PowerShell + WPF (XAML) → переносной exe
без установки и зависимостей; звуки и картинки генерируются
при первом запуске.

| Утилита | Что делает |
|---|---|
| [T-REX Metronome](https://github.com/amjedy-lab/t-rex-metronome) | Виджет «метроном + таймер» для тренировок (в первую очередь барабанных): 30–300 BPM, размеры такта, сильные доли, дробление (восьмые / шестнадцатые / триоли), лог тренировок JSONL. Сделал сам, потому что не нашёл метроном, подходящий для встраивания в ИИ-сценарии обучения игре на барабанах |
| [T-REX Backup 1C](https://github.com/amjedy-lab/trex-backup-1c) | Бэкап файловых баз 1С: архивация по расписанию и вручную, лог в SQLite, уведомления ntfy на телефон |

Всё, что делаю для своего рабочего процесса и нахожу полезным, — публикую здесь.
