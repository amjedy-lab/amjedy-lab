# Hi, I'm Valentin (@amjedy-lab) 🦖

**T-REX utilities** — small, portable Windows tools written as single-file
PowerShell + WPF (XAML) scripts and compiled to standalone `.exe`:
no installation, no dependencies, sounds and assets generated on first launch.

| Utility | What it does |
|---|---|
| **[T-REX Metronome](https://github.com/amjedy-lab/t-rex-metronome)** | Metronome & practice-timer desktop widget: 30–300 BPM, time signatures, accented beats, subdivisions (eighths / sixteenths / triplets), JSONL training log |

More utilities are on the way — everything I build for my own workflow
and find useful, I publish here.
